# 惡的製造所 — 神奇海獅講座筆記

2026 年 9 月 12 日（六），李博研（神奇海獅先生）在台北南京東路三段 9 號 4F「白盒子」的講座
「惡的製造所——獨裁者如何打造完美救世主？從納粹崛起看當代社會：我們如何識別危險？」。
爸爸帶大兒子去聽，這是聽完之後整理的聽講筆記與投影片相簿。

純靜態 HTML + CSS + JS，無框架、無建置步驟。

## 內容

- `index.html`：四階段總覽、三章筆記、結論、現場問答、投影片相簿
- `img/full/`、`img/thumb/`：39 張現場投影片照片與 560px 縮圖
- `app.js`：相簿與燈箱的投影片資料

本機預覽：`node build/serve.js`，開 <http://localhost:5180>。

## 部署

- GitHub Pages：main 分支根目錄
- Cloudflare Pages：Git 連結，push 到 main 自動部署

已設定 noindex 與擋 AI 爬蟲（`robots.txt`、`_headers`、每頁 meta）。

## 著作權

講座內容與投影片的著作權屬講者與主辦單位漢薩文化。本站為個人聽講筆記，非官方文字。
